# Netflix Data Analysis

This project performs exploratory data analysis on the Netflix Movies and TV Shows dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Goals
- Explore Netflix content trends
- Analyze distribution of movies and TV shows
- Identify top genres and countries producing content
- Visualize content growth over time

## Key Insights
- Netflix hosts significantly more movies than TV shows
- The United States produces the largest amount of Netflix content
- Drama and international movies are among the most common genres
- Netflix experienced major content growth after 2015

## Dataset
Netflix Movies and TV Shows dataset from Kaggle.
